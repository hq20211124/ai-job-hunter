# 岗位筛选与去重规则

> 这套规则是从「广东 7 城 250 个原始岗位 → 筛到 218 个 → 实际投递」的完整过程里磨出来的。
> 照着用可以避免投到外包岗、避免重复投递、避免把时间浪费在点不动的按钮上。
>
> 配套命令：`agent/scrape-jobs.js`（抓取）→ `agent/rank-jobs.py`（过滤打分）→ 投递流水线。

---

## 0. 全流程

```
scrape-jobs.js          按 城市 × 关键词 抓列表页  →  gd-jobs.json
      ↓
rank-jobs.py            过滤 + 匹配度打分          →  gd-jobs-ranked.json
      ↓
（可选）人工/脚本二次收紧  →  jobs-queue.json
      ↓
投递前逐个开详情页        读【真实薪资】+【按钮状态】→  queue-prechecked.json
      ↓
apply-jobs.js           逐个投递 + 发定制招呼语     →  apply-results.json（只追加）
```

**每一步为什么存在**，见下面各节。

---

## 1. ⚠️ 列表页的薪资是假的，必须去详情页读

**BOSS直聘在搜索结果列表页用 Unicode 私有区码点（`U+E0xx`）做字体混淆反爬。**

抓下来的"薪资"字段长这样：

```
U+E032 U+E036 "-" U+E032 U+E037 "K"
```

它是**假字符**，不是数字 —— 用普通的数字正则解析会得到空值，或者错误的数字。

**解决**：职位**详情页**的 `.salary` 是明文。

```js
await goto(jobUrl);
const salary = await pe(`(function(){
  const e = document.querySelector('.salary');
  return e ? String(e.innerText).trim() : '';
})()`);
// → "30-40K·14薪"
```

**结论：薪资一律在详情页读，不要相信列表页的 salary 字段。**

---

## 2. ⚠️ 去重不能看会话列表，要看详情页按钮

**BOSS直聘的消息会话列表只保留最近 40 条** —— 滚到底、点「滚动加载更多」都不会增加；
新会话进来，旧会话被挤掉。

所以 **「会话列表里没有」≠「没投过」**。

**唯一可靠的判据在职位详情页**：

| 按钮文案 | 含义 | 动作 |
|---|---|---|
| 「立即沟通」 | 没投过 | 可以投 |
| 「继续沟通」 | 已经投过了 | **跳过** |

> **真实教训**：曾经按会话列表去重后去投，队列前 16 个岗位全部显示「继续沟通」——
> 它们早就投过了，只是会话被挤出了 40 条窗口。白跑一轮。

**投递脚本要在点按钮前读一次按钮文案**，而不是只信本地的投递历史。

## 3. 排除规则

### 3.1 外包 / 驻场 / 人力派遣公司（按公司名）

用户底线是**不接受外包和驻场**。以下公司名特征实测有效：

```python
EXCLUDE_COMPANY = [
    # 人力 / 派遣 / 外包服务商
    r'人力', r'人才', r'劳务', r'外服', r'派遣', r'外包', r'企业管理',
    r'万宝盛华', r'人瑞', r'人惠', r'中智', r'仁联', r'科锐', r'高凡',
    r'拓保', r'博才', r'易才', r'朗钧', r'外企德科', r'FESCO',
    r'佰钧成', r'中科铭天', r'腾信软创', r'网新', r'赛意', r'华立数字',
    r'中软国际', r'软通动力', r'中电金信', r'文思海辉', r'博彦', r'法本',
    r'同海科技', r'同方鼎欣', r'中科软',
    # 红旗：非软件企业却挂高薪软件岗
    r'贸易商行', r'商行', r'贸易公司',
]
```

**华为系（社招基本都是 OD 外包）单独处理**：

```python
EXCLUDE_COMPANY_STRICT = [r'^华为', r'华为技术', r'华为云']
```

**非 IT 行业却挂 IT 岗**（多为壳公司/中介）：

```python
EXCLUDE_COMPANY_ODD = [r'婚姻', r'餐饮', r'口腔', r'健身', r'美发', r'医养']
```

> **名单是活的**。每投一批，检查一遍实际投出去的公司，发现新的外包商就补进来。

### 3.2 非开发岗（按职位名）

```python
EXCLUDE_TITLE = [
    r'机器视觉', r'电源', r'项目经理', r'车间', r'班长', r'销售', r'测试',
    r'运维', r'实施', r'UI设计', r'视觉设计', r'产品经理', r'运营', r'讲师',
    r'硬件', r'结构', r'电气', r'机械', r'采购', r'健身', r'美发', r'发型',
    r'财务', r'编辑', r'顾问$', r'设计师',
]
```

**为什么需要它**：BOSS 的标题里带「高级」不代表是开发岗。
实测漏进来过：`高级发型设计师`、`高级健身教练`、`高级美发师`、`采购经理/高级买手`、
`高级财务经理`、`高级电源工程师`、`高级机械工程师`、`高级生产班长/车间主任`。

这类岗位会**命中「工业/MES/制造」之类的加分关键词**，光靠打分过滤不掉。

### 3.3 级别严重不符

```python
r'初级', r'应届', r'校招', r'实习', r'接受应届', r'2027届', r'25考研'
```

### 3.4 项目制 / 驻场信号（按职位名）

```python
r'独立顾问', r'周期6个月', r'短期半年', r'1年周期', r'3个月', r'技术合伙人'
```

> 「独立顾问」「周期6个月」这类措辞，本质是按项目外包。

### 3.5 JD 层面的驻场检测（**注意否定语境**）

职位名可能看不出来，要读 JD：

```js
function outsourceSignal(jdText) {
  // 排除否定语境：有的公司会专门写「自研非外包」「无需驻场」，那是好事
  const NEG = /(无需|不需要|不用|非|不)驻场|自研非外包|非外包|无外包|不是外包|不涉及外包/;
  const hits = [];
  if (/驻场/.test(jdText) && !NEG.test(jdText)) hits.push('驻场');
  return hits;
}
```

> **真实案例**：一家公司的 JD 里出现「外包」两个字，粗看要排除；
> 读上下文才发现写的是「**自研非外包**」（某交易所旗下金融科技公司）—— 差点误杀一个好岗位。

## 4. 匹配度打分

`rank-jobs.py` 里的 `SCORE`，格式是 `'标签': (正则, 分值)`：

```python
SCORE = {
    '金融/证券/期货/基金': (r'金融|证券|期货|基金|量化|投研|资管|理财|银行|保险|支付', 5),
    'AI/大模型/智能体':    (r'AI|人工智能|大模型|LLM|智能体|LangChain|Agent', 5),
    '架构/技术负责人':      (r'架构|技术负责人|组长|Leader|技术经理|Team', 4),
    '微服务/SpringCloud':  (r'微服务|Spring\s*Cloud|SpringCloud|Nacos|分布式', 3),
    ...
}
```

**打分的作用是排序，不是过滤。** 分高的先投，分低的排后面 —— 因为投递有每日上限，
把配额花在最匹配的岗位上。

> ⚠️ **0 分不代表垃圾**。实测：一些正经公司（机器人、家电、纸业等）发的 Java 岗
> 因为标题朴实、没命中任何关键词，得分是 0。**放宽投递量时可以把 0 分的一起投。**

---

## 5. 阈值与人工复核

| 参数 | 建议 | 说明 |
|---|---|---|
| `min_score` | 0 | 打分只用来排序；设 >0 会漏掉正经但标题朴实的岗位 |
| 薪资门槛 | 按需 | 详情页读到的**上限**低于阈值则跳过；用户说「工资多少都行」时设 0 |
| 一次投递量 | 20-30 | 见 README 的反风控章节 |

**每批投完做一次复核**：把实际投出去的公司名过一遍，看有没有漏网的外包商，
有就补进黑名单 —— 名单是这么滚起来的。

## 6. 已知还没解决的筛选问题

| 问题 | 表现 | 可能的解法 |
|---|---|---|
| **招聘方与岗位公司名不一致** | 岗位写「A 公司」，点开沟通发现 HR 是「B 人力资源公司」的猎头 | 投递前读会话里 HR 的所属公司，与岗位公司比对 |
| **非 IT 行业挂 IT 岗难以枚举** | 婚庆、餐饮、口腔门诊都在招「Java」 | 行业黑名单 + 人工抽查 |
| **薪资是日薪/计件** | 详情页显示「550-1000元/天」 | 解析时识别单位，日薪按 21.75 天折算 |
