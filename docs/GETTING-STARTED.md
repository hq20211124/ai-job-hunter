# 上手清单 —— 从下载到投出第一份简历

> 这份文档是给**新用户和你的 AI 助手一起看**的。
> 目标：**照着走完，就能开始投简历，不需要再探索。**
>
> 如果你是用 AI 助手（DeepSeek Harness / Claude Code / Cursor 等）代劳，直接把
> [第 8 节那段开场提示词](#8-交给-ai-助手时把这段发给它) 复制给它即可。

---

## 0. 先搞清楚：哪些必须你做，哪些助手能做

| 事情 | 谁做 | 为什么 |
|---|---|---|
| 装 Node.js / Chrome / Python | **你** | 环境准备 |
| 装浏览器扩展 | **你** | Chrome 不允许程序代装 |
| 启动本地代理 | 助手 | 一条命令 |
| **在四个平台手动登录一次** | **你** | 要扫码或验证码 |
| **准备简历数据、生成简历** | 你（助手可代填模板） | 内容必须是你的真实经历 |
| **上传简历附件到四个平台** | **你** | 浏览器禁止脚本设置文件选择框，这是唯一的硬边界 |
| **在智联设置自定义招呼语** | 你（或助手代点） | 不设的话发的是平台默认话术 |
| 抓岗位 / 筛选 / 投递 / 查回复 | 助手 | 全是脚本 |
| 决定薪资底线、外包要不要去 | **你** | 只有你知道 |

> **一句话**：助手负责「手和眼睛」，你负责「登录、传附件、拍板」。

## 1. 前置条件

| 依赖 | 版本 | 检查命令 | 用途 |
|---|---|---|---|
| Node.js | 18+ | `node --version` | 跑代理和所有脚本 |
| Google Chrome | 111+ | 地址栏 `chrome://version` | 扩展要 MV3 的 `world: "MAIN"` |
| Python | 3.8+ | `python --version` | 可选，只有筛选/建队列脚本需要 |

## 2. 装好（三步）

```bash
# ① 装依赖
cd agent
npm install          # 实际只依赖 ws

# ② 启动代理（保持这个窗口开着）
node agent.js
# 期望看到： [agent] ✅ 扩展已就绪，可以下命令了

# ③ 新开一个窗口，验证连通
curl http://127.0.0.1:61823/status
# 期望： {"extensionConnected":true,"wsPort":61822}
```

**扩展的安装**在你自己的 Chrome 里做（程序装不了）：

```
chrome://extensions → 打开右上角「开发者模式」→
「加载已解压的扩展程序」→ 选项目里的 extension/ 目录
```

> ⚠️ 初次安装后，如果代理一直显示「等待扩展连接」，等 30 秒，
> 或者刷新任意网页 / 点一下扩展图标手动触发重连。

详细的分步教程（含截图说明和排错）见 [`TUTORIAL.md`](TUTORIAL.md)。

## 3. 登录四个平台（**必须你手动做，只做一次**）

用你平时的方式登录（扫码或密码都行），助手复用你的真实登录态：

| 平台 | 地址 |
|---|---|
| BOSS直聘 | <https://www.zhipin.com> |
| 智联招聘 | <https://www.zhaopin.com> |
| 前程无忧 | <https://www.51job.com> |

**登录状态有有效期**。用着用着突然操作失败，第一件事就是回来看是不是掉登录了。

## 4. 准备简历（这一步最容易漏）

### 4.1 填你的真实数据

```bash
cp resume/profile.example.json resume/profile.json
# 然后编辑 resume/profile.json，把里面的示例数据换成你的
```

`profile.json` **已被 .gitignore 排除**，你的个人信息不会进仓库。

> ⚠️ **只写你真做过的事。** 编造的量化数字（"提升 40% 性能"）面试一问就穿帮。
> 这是这个项目三条红线里的第一条。

### 4.2 生成简历文件

```bash
python resume/build_resume.py resume/profile.json -o resume/我的简历.docx
# 再转成 PDF（用任意 Office 工具，或 LibreOffice）
```

### 4.3 上传到四个平台 —— **这一步只能你来**

**浏览器出于安全禁止脚本设置文件选择框**，所以附件上传自动化不了。

| 平台 | 附件入口 |
|---|---|
| BOSS直聘 | 简历页侧栏「附件管理」 |
| 智联 | `i.zhaopin.com/resume` → 「附件简历」 |
| 前程无忧 | `www.51job.com/resume/center` → 「附件管理」 |
| 猎聘 | `c.liepin.com/resume/edit` → 「附件简历」 |

> ⚠️ **必须投递之前传好。** 一旦开始批量投递，HR 点开看到的就都是这个版本了，传错要一家家补发。
> （本项目真实踩过这个坑：61 个岗位投完才发现附件是旧的。）

### 4.4 顺手把「在线简历」也填好

各平台的在线简历是 HR 第一眼看到的东西，通常比附件更重要。
填法见 [`PLATFORMS.md`](PLATFORMS.md) 各平台章节（含「字段有字数上限」「日期必须回车」这些坑）。

## 5. 设好各平台的「打招呼语」

**不设的话，投递时发出去的是平台默认话术**，白瞎一次接触机会。

| 平台 | 在哪设 | 说明 |
|---|---|---|
| **智联** | `i.zhaopin.com/im/greeting/setting` → 「招呼语」→「**自定义**」标签 | ⚠️ 默认显示的是「常规」标签，自己加的条目在「自定义」里，看不到别以为没保存 |
| **BOSS** | 投递时脚本按 JD 现写（`agent/apply-jobs.js` 里的 `buildGreeting`） | 不需要预设 |
| **前程无忧 / 猎聘** | 投递时会带上默认招呼语 | 目前用平台默认 |

**智联自定义招呼语示例**（可直接改用）：

```
您好，我 X 年 Java 后端：<你最拿得出手的两段经历>。
想先确认一下：这个岗位是甲方直招吗，有没有外包或驻场？我不考虑外包和驻场。
方便的话也说下团队规模和技术栈，聊聊看是否合适。
```

> 为什么把「是否外包/驻场」放在招呼语里：**一开始就问，比聊到后面才发现是外包省时间。**

## 6. 跑起来（助手执行）

### 6.1 抓岗位 → 打分 → 建队列

```bash
cd agent

# ① 抓岗位（先改脚本里的 CITIES 和 KEYWORDS 成你的城市和方向）
node scrape-jobs.js
#    → data/gd-jobs.json

# ② 过滤 + 打分 + 排序（用 --help 看参数）
python rank-jobs.py data/gd-jobs.json
#    → data/jobs-ranked.json

# ③ 二次收紧成投递队列（外包黑名单在这一步生效）
python build-queue.py
#    → data/jobs-queue.json  +  data/queue-review.txt（剔除原因，建议人工扫一眼）
```

**筛选规则集中在 [`agent/filters.json`](https://github.com/hq20211124/ai-job-hunter/blob/main/agent/filters.json)**
（JS 和 Python 共用一份）。要加黑名单公司、调排除规则，只改这一个文件。
规则说明见 [`SCREENING.md`](SCREENING.md)。

### 6.2 投递

```bash
# BOSS直聘（序号对应 data/jobs-queue.json）
node apply-jobs.js 1 20 --min=0

# 智联招聘（城市码 jl）
node apply-jobs-zhaopin.js 763 Java 10

# 前程无忧（城市码 jobArea）
node apply-jobs-51job.js 030200 Java 10

# 猎聘（⚠️ 风控最高，单次 3-5 个）
node apply-jobs-liepin.js 050020 Java 3
```

**城市码对照表**（东莞/中山/惠州这几个不能靠规律猜）：

| 城市 | BOSS | 智联 | 前程无忧 | 猎聘 |
|---|---|---|---|---|
| 广州 | 101280100 | 763 | 030200 | 050020 |
| 深圳 | 101280600 | 765 | 040000 | 050090 |
| 东莞 | 101281600 | **779** | 030800 | **050040** |
| 佛山 | 101280800 | 768 | 030600 | 050050 |
| 中山 | 101281700 | **780** | 030700 | 050130 |
| 珠海 | 101280700 | 766 | 030500 | 050140 |
| 惠州 | 101280300 | **773** | 030300 | **050060** |

其它城市见 [`PLATFORMS.md`](PLATFORMS.md) 各平台章节。

**投递前先 `--dry` 跑一遍看筛选结果**，别直接放量。

### 6.3 查回复

```bash
node check-replies.js          # 查全部支持的平台
node check-replies.js boss     # 只查 BOSS
```

> ⚠️ **BOSS 的 HR 回复容易漏**：会话列表只保留最近 100 条，
> 而且必须点「未读」标签才看得到 —— 这个标签**点开一次就标记为已读**。
> `check-replies.js` 已经处理好了，别自己手写循环。

## 7. 节奏（**先看这份再放量**）

| 平台 | 单次批量 | 岗位间隔 | 单日上限 |
|---|---|---|---|
| BOSS直聘 | 20–30 | 12–27 秒 | 30–50 |
| 智联招聘 | 10–20 | 8–18 秒 | 30–50 |
| 前程无忧 | 10–20 | 7–16 秒 | 30–50 |
| 猎聘 | **3–5** | **15–25 秒** | **10** |

**看到这些信号立刻停**：验证码 / 滑块 / 要求重新登录 / 「账号行为异常」/ 消息发不出去。

> 完整的风控复盘和判断信号表见 [`RISK-CONTROL.md`](RISK-CONTROL.md)。
> 里面有一条最反直觉的结论：**失败的循环比成功的循环更危险。**

## 8. 交给 AI 助手时，把这段发给它

```
我在本地跑了一个浏览器自动化项目，用来在招聘网站上投简历。

项目路径：<你的项目绝对路径>

请先读这两份，再动手：
- docs/GETTING-STARTED.md   上手清单（从下载到投递的完整步骤）
- docs/PLATFORMS.md         四个平台的操作手册（入口、按钮、城市码、各种坑）

然后按顺序：
1. 检查代理是否在跑（curl http://127.0.0.1:61823/status），没跑就启动
   node agent/agent.js
   （注意：我日常用的 Chrome 必须开着，扩展在上面）
2. 告诉我现在处在清单的哪一步，哪些还没做
3. 按清单继续

注意事项：
- 临时脚本放 data/，不要进 git 仓库
- 改简历前先确认改动内容，投递前先确认附件版本
- 不要编造我的经历或数字
- 涉及承诺的事（面试时间、期望薪资、到岗时间）必须我拍板
```

## 9. 一次性配置 vs 日常操作

**只做一次：**

- [ ] Node.js / Chrome / Python 装好
- [ ] 代理能启动，`/status` 返回 `extensionConnected: true`
- [ ] 扩展装好并固定在工具栏
- [ ] 四个平台各登录一次
- [ ] `resume/profile.json` 填好真实数据
- [ ] 简历生成并**上传到四个平台的附件**
- [ ] 四个平台的**在线简历**填好
- [ ] 智联的自定义招呼语设好
- [ ] `agent/scrape-jobs.js` 里的 `CITIES` / `KEYWORDS` 改成你的
- [ ] `agent/filters.json` 里的外包黑名单按你的情况调整

**每天都做：**

- [ ] Chrome 开着、代理在跑
- [ ] `node check-replies.js` 看有没有 HR 回复
- [ ] 投一批（按第 7 节的节奏）
- [ ] 遇到验证码 / 异常提示就停手

## 10. 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `/status` 返回 `extensionConnected: false` | 扩展没连上 | Chrome 开着吗？等 30 秒；`chrome://extensions` 里扩展是启用的吗；刷新任意网页 |
| 命令报 `Unknown: xxx` | 改了 `extension/` 里的代码但没重载 | Chrome 不会热重载扩展，去 `chrome://extensions` 点 ⟳ |
| 脚本报 `Cannot find module 'ws'` | 没装依赖 | `cd agent && npm install` |
| 脚本找不到 `data/jobs-queue.json` | 还没建队列 | 先跑第 6.1 节那三步 |
| 投递跑完但 HR 那边没反应 | 可能只发了招呼语没发简历 | BOSS 只发招呼语；智联/前程无忧/猎聘会一起发简历 |
| 点按钮没反应 | 合成事件对某些组件无效 | 见 [`TUTORIAL.md`](TUTORIAL.md) 的「四级递进」和 [`PLATFORMS.md`](PLATFORMS.md) 各平台的具体解法 |
| 掉登录了 | 登录态过期 | 手动重新登录一次 |

## 11. 这个项目**不会**帮你做的事

读之前先确认你的预期：

- ❌ **不会绕过验证码**。遇到就停下来你自己处理 —— 这是刻意保留的边界。
- ❌ **不会自动上传附件**。浏览器禁止脚本设置文件选择框。
- ❌ **不会保证不被风控**。任何自动化都有风险，请严格按第 7 节的节奏。
- ❌ **不会替你判断该去哪家**。外包、薪资、城市这些底线只有你清楚。
- ❌ **页面改版就会失效**。招聘网站改 DOM 是常事，脚本里的选择器需要跟着改 ——
  这也是为什么 `docs/` 下那几份文档要写清楚「为什么这样做」，而不只是「怎么做」。
